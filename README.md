Repositorio destinado a almacenar las prácticas, ejercicios, scripts de automatización e infraestructura utilizados en el módulo de **Despliegue de Aplicaciones Web**.

---

## 🛠️ Contenidos y Tecnologías

En este repositorio se recogen recursos sobre:

* **Servidores y Virtualización:** Configuración e hipervisores (Proxmox, máquinas virtuales, contenedores).
* **Cloud Computing:** Provisionamiento y administración de recursos en la nube mediante **AWS CLI** (VPCs, subnets, instancias EC2).
* **Scripting y Automatización:** Desarrollo de scripts en **Bash** para el despliegue automático de infraestructura.
* **Redes y Administración:** Configuración de servicios de red, protocolos y enrutamiento.
